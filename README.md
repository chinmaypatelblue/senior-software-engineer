# Interview Prep Work

This folder contains the minimum materials needed to complete an offline market data parsing exercise.

Start here:

1. Read `requirements.md`.
2. Review the documents in `resources/`.
3. Use the session materials in `sessions/2026-01-21/`.

What is provided:

- a short problem statement
- source PDF documentation
- one session-specific PCAP capture

Expected candidate outcome:

- decode the relevant top-of-book messages from the provided PCAP
- produce a small, correct, explainable implementation
- document assumptions and any simplifications

## Data Warning

The provided data is sanitized and is included only for this exercise.
It has no connection to real assets, real instruments, or real prices.
Any similarity or comparison to actual assets, securities, symbols, or market prices is purely coincidental.
